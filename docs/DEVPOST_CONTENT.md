# VaultMind AI

Tagline: Find the evidence. Review the action. Keep control of your files.

Track: Automate Your Workflow.

## Inspiration

A NAS can hold years of useful context, but finding one warranty or deciding which duplicate matters still takes effort. VaultMind connects file understanding to a carefully reviewed organization workflow.

## What it does

The Skill orchestrates supported file and document experts to find evidence, compare versions, review duplicates and flag possible private content inside an authorized scope. SafeAction Planner shows exact proposed moves with evidence and risks; changed sources or destination conflicts must block execution. Recovery requires a fresh approved inverse plan.

## How it was built

Original SKILL.md orchestration and five Markdown references, authored against UGREEN's official 0.7.3 creation kit and catalog 2.0.0. The official static checker passes. No executable, database, custom model or web app is included in the Skill ZIP. An independent local workbench demonstrates lexical search and simulated action policies on synthetic fixtures.

## Honest status

Round 1 pre-test package. No NAS installation or runtime validation has been performed. Workstation tests and benchmarks are available in the repository but do not demonstrate NAS performance. The local deterministic policy engine is a reference simulation; actual guard enforcement belongs to the platform.
